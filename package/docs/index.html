Começar

Instalação

Escolha o caminho que combina com seu projeto. Todas as classes usam o prefixo st- e os tokens ficam em variáveis CSS --st-*.

1 · Via npm
npm install @storielle/design-system

/* no seu CSS ou entrypoint JS */
import "@storielle/design-system";
2 · Direto no HTML
<link rel="stylesheet" href="storielle.css">

<body class="st-body">
  <div class="st-grid-bg"></div>
  <button class="st-cta">Start Your Blueprint</button>
</body>
3 · Preset do Tailwind (mesmos tokens como utilitários)
// tailwind.config.js
module.exports = {
  presets: [require("@storielle/design-system/tailwind")],
};
// uso: bg-st-surface text-st-dim border-st-border font-display rounded-st-xl
